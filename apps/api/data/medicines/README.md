# Allergy medicine dataset

Curated seed for the shared `catalog.medicines` table: препараты, которые чаще всего
встречаются у пациентов с аллергией в РФ, с типовыми торговыми названиями.

- **Файл:** `allergy-medicines.json`
- **Заливка:** `pnpm --filter api db:seed-medicines` (см. `src/db/seed-medicines.ts`) —
  идёт через `POST /api/medicines`, не пишет в базу напрямую.
- **Источник данных:** официальные инструкции по применению (ГРЛС,
  https://grls.rosminzdrav.ru) для препаратов, зарегистрированных в РФ.
- **Дата сверки:** 2026-08-24.

## Что внутри

Группы: H1-антигистаминные 2-го поколения (цетиризин, левоцетиризин, лоратадин,
дезлоратадин, фексофенадин, эбастин, рупатадин, биластин), H1 1-го поколения
(хлоропирамин, клемастин, диметинден), интраназальные ГКС (мометазон, флутиказон,
будесонид, беклометазон), кромоны и азеластин, глазные капли, солевые растворы,
антилейкотриеновые (монтелукаст), топические ГКС и такролимус, системные ГКС и
эпинефрин для тяжёлых реакций.

Каждое типовое торговое название — отдельная запись с тем же `activeSubstance`,
потому что каталог дедуплицируется по `normalizedName` от `name`, а автодополнение
в дневнике матчит и название, и действующее вещество: ввод «зирт» находит Зиртек,
ввод «цет» — и Цетрин, и цетиризин.

## Правила заполнения

| Поле | Правило |
|------|---------|
| `name` | Торговое название без дозировки («Зиртек», не «Зиртек 10 мг»). Разные формы одного бренда — разные записи («Зиртек» и «Зиртек капли»). |
| `activeSubstance` | МНН строчными буквами. Обязательно для каждой записи. |
| `strength`, `form` | Как в инструкции. Дозировка живёт здесь, не в названии. |
| `ageUsage`, `minAgeYears` | Только из инструкции. Где сведений нет — поле пустое. Для рецептурных — без `dose`, только `note` про назначение врача. |
| `prescriptionOnly` | Метаданные датасета (в API не отправляются): защищают инвариант «у рецептурных нет доз». |
| `ingredients` | Не заполняем: состав вспомогательных веществ отличается у разных производителей и должен читаться с конкретной упаковки. |
| `allergenTags` | Пусто по умолчанию. Аллергенные метки не выводятся из состава автоматически (`docs/development-rules.md` §2.4). |
| `confidence` | `high` — дозы взрослых/детских схем сверены; `medium` — включена только часть схемы или данные производителя различаются. |

Незарегистрированные в РФ формы не добавляем: автоинжектор адреналина в датасет не
входит, для анафилаксии есть запись по действующему веществу с пометкой о назначении
врача.

Астма-препараты (монтелукаст) описаны нейтрально, без порогов и схем терапии — они
остаются в `@allerguide/core` по ориентирам GINA (`docs/development-rules.md` §2.5).

## Дисклеймер

Карточки — справочная информация, а не рекомендация к приёму. В приложении рядом с
ними показывается `MEDICINE_CONTRAINDICATION_DISCLAIMER` из `@allerguide/core`.
