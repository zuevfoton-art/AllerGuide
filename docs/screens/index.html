Экранные формы A-Claro

As-is макеты существующих экранов для правок в Cursor Canvas и handoff в apps/mobile. Инструкция: README.md. Референс токенов: design-mockup.html.

Макет Route Код Состояния
sos.html /(tabs)/sos app/(tabs)/sos.tsx default · empty profile
home.html /(tabs)/home app/(tabs)/home.tsx default · loading
diary.html /(tabs)/diary app/(tabs)/diary.tsx default · empty history
scanner.html /(tabs)/scanner app/(tabs)/scanner.tsx default · result safe · error
Приоритет handoff: SOS → Home → Diary → Scanner.
Токены: _tokens.css ↔ apps/mobile/src/constants/theme.ts. Имена блоков в макетах (data-component) совпадают с компонентами в коде.
