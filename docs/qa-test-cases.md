## 3. Формат тест-кейса

Каждый кейс содержит: **ID**, **Название**, **Приоритет**, **Платформа**, **Предусловия**, **Шаги**, **Ожидаемый результат**.

## 4. Bootstrap и маршрутизация

### TC-001 — Первый запуск без сессии
- **Приоритет:** P0 | **Платформа:** All
- **Предусловия:** Приложение не запускалось / данные очищены
- **Шаги:** Открыть приложение
- **Ожидаемый результат:** Редирект на `/login`

### TC-002 — Неавторизованный доступ к главной
- **Приоритет:** P0 | **Платформа:** All
- **Предусловия:** Пользователь не авторизован
- **Шаги:** Перейти по URL `/(tabs)/home`
- **Ожидаемый результат:** Редирект на `/login`

### TC-003 — Маршрут после логина: intro не пройден
- **Приоритет:** P0 | **Платформа:** All
- **Предусловия:** Новый пользователь, `introComplete = false`
- **Шаги:** Войти в аккаунт
- **Ожидаемый результат:** Редирект на `/onboarding-intro`

### TC-004 — Маршрут после intro: нет профилей
- **Приоритет:** P0 | **Платформа:** All
- **Предусловия:** Авторизован, intro пройден, профилей нет
- **Шаги:** Открыть `/`
- **Ожидаемый результат:** Редирект на `/onboarding`

### TC-005 — Маршрут: сценарий both без обоих профилей
- **Приоритет:** P0 | **Платформа:** All
- **Предусловия:** Сценарий `both`, есть только профиль `self`
- **Шаги:** Открыть `/`
- **Ожидаемый результат:** Редирект на `/profile-setup`

### TC-006 — Маршрут: полный онбординг завершён
- **Приоритет:** P0 | **Платформа:** All
- **Предусловия:** Авторизован, intro пройден, профили созданы, onboarding завершён
- **Шаги:** Открыть `/`
- **Ожидаемый результат:** Редирект на `/(tabs)/home`

### TC-007 — Splash не зависает
- **Приоритет:** P1 | **Платформа:** All
- **Предусловия:** Любое валидное состояние
- **Шаги:** Открыть приложение, дождаться bootstrap
- **Ожидаемый результат:** Splash исчезает ≤ 5 сек, открывается целевой экран

### TC-008 — Deep link на settings
- **Приоритет:** P1 | **Платформа:** All
- **Предусловия:** Авторизован, онбординг завершён
- **Шаги:** Перейти на `/settings`
- **Ожидаемый результат:** Экран настроек открывается без ошибок

## 5. Аутентификация

## 20. Чек-лист ручного прогона

[ ] Регистрация и вход работают

[ ] Профиль создаётся, аллергены выбираются, переключение работает
[ ] Дневник: быстрая запись, полный мастер, редактирование, удаление

[ ] Сканер: ручной ввод, вердикт, история
[ ] SOS: карточка read-only, контакты, вызов скорой; правки из профиля
[ ] Главная: бренд-header, двухслойный wellness, быстрые действия
[ ] Карта: 3 слоя открываются
[ ] Отчёт для врача генерируется
[ ] Настройки: тема, язык, номер скорой
[ ] Logout / повторный вход — данные на месте
[ ] Offline: CRUD работает без сети
[ ] Дисклеймеры на медицинских экранах
[ ] Web: адаптивная вёрстка, ограничения камеры/напоминаний
[ ] Native: камера, геолокация, PDF sharing, импорт бэкапа
