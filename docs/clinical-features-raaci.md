# Клинические функции AllerGuide (ориентиры РААКИ)

Спецификация улучшений по мотивам [сборника клинических рекомендаций РААКИ](https://raaci.ru/dat/pdf/akd.pdf). Документ описывает реализованные возможности, принципы UX и границы ответственности приложения.

## Принципы UX

1. **Progressive disclosure** — на экране SOS и в дневнике по умолчанию показывается компактная сводка; детали раскрываются по запросу.
2. **Один чип «Шкала»** вместо четырёх отдельных разделов — выбор типа шкалы внутри мастера.
3. **Автоподстановка контекста** в разделе «Триггер» (пыльца, сканы, ЛС) без лишних полей на главном экране.
4. **Информационный характер** — приложение не ставит диагноз и не назначает лечение.

## 1. Цифровой паспорт аллергика (SOS)

### Данные паспорта

| Поле | Описание |
|------|----------|
| Аллергены | Из профиля (read-only на SOS) |
| Непереносимые ЛС | Список препаратов, введённый пользователем |
| Триггеры | Пыльца, пища, животные и др. |
| Адреналин | Марка, срок годности, где хранится |
| Врач | Имя и телефон лечащего аллерголога |
| История анафилаксии | Флаг «была тяжёлая реакция» |
| Набор первой помощи | Чеклист предметов |

Хранение: `app_settings` → ключ `sosPassport:{profileId}` (JSON, версия `v: 1`).

### Алгоритм анафилаксии (справочно)

| Степень | Признаки | Ориентиры действий |
|---------|----------|-------------------|
| 1 | Кожа/слизистые | Антигистаминное по назначению врача, наблюдение |
| 2 | + дыхание, ЖКТ, лёгкие сердечно-сосудистые | Адреналин по плану врача, вызов 103 |
| 3 | Шок, обструкция дыхания | Адреналин немедленно, 103, положение на спине с приподнятыми ногами |

**Бифазная реакция:** предупреждение о возможном повторном ухудшении в течение 4–6 часов — показывается на экране SOS при раскрытии блока анафилаксии.

### Экспорт

- Текстовая сводка для медработника (кнопка «Поделиться»).
- PDF через `expo-print` (тот же механизм, что отчёт для врача).

## 2. Мини-шкалы в дневнике

Отдельный раздел **«Шкала»** — опциональный, не входит в полный мастер записи по умолчанию.

Шкалы подбираются по профилю (`diary-profile.ts`): ринит/поллиноз → ARIA-lite, астма → ACT, атопический дерматит → SCORAD-lite. Типы состояний задаются в профиле и дополняются эвристикой по аллергенам. Разделы «Пикфлоуметрия» и «АСИТ» показываются только при соответствующих состояниях (FR-PROF-10/11).

### ARIA-lite (ринит)

4 симптома по шкале 0–3: заложенность, ринорея, чихание, зуд. Сумма 0–12 → интерпретация: лёгкая / умеренная / выраженная.

### ACT (астма)

5 вопросов по шкале 1–5. Сумма 5–25:

- ≥ 20 — хороший контроль
- 16–19 — частичный контроль
- ≤ 15 — неконтролируемая астма (консультация врача)

### SCORAD-lite (атопический дерматит)

Упрощённая оценка: площадь поражения (%), зуд 0–10, нарушение сна 0–3. Приближённый балл для тренда, не заменяет клинический SCORAD.

### UAS7 (крапивница, дневная запись)

Число элементов сыпи (0 / 1–6 / 7–12 / >12) и зуд 0–3. Для недельного UAS7 врач агрегирует записи из отчёта.

### Валидация

`validateClinicalScale(scaleId, answers)` в `packages/core/src/clinical-scales.ts` — проверка обязательных полей и диапазонов перед сохранением записи дневника.

## 3. Связка дневника с триггерами

При открытии раздела «Триггер» автоматически подставляется контекст (`buildTriggerPrefill`):

| Источник | Поле дневника | Данные |
|----------|---------------|--------|
| Wellness / Open-Meteo | `pollenContext` | Уровень пыльцы по профильным аллергенам |
| Сканер | `recentScan` | Последнее сканирование за 24 ч |
| Дневник «Лекарство» | `todayMeds` | Препараты, принятые сегодня |

Пользователь может отредактировать или очистить подставленные значения.

## 4. Отчёт для врача v2

Новые блоки в `DOCTOR_REPORT_BLOCKS`:

| Блок | Содержание |
|------|------------|
| `scales` | Записи «Шкала» с итоговым баллом и интерпретацией |
| `triggerContext` | Триггеры с контекстом пыльцы, сканов и ЛС |

Дополнительно в PDF:

- **Тренд ПСВ** — min / max / последнее значение за период.
- **Сводка шкал** — последние оценки по каждому типу.
- **Паспорт SOS** — краткая выжимка (аллергены, непереносимые ЛС, адреналин).

## 5. АСИТ (аллерген-специфическая иммунотерапия)

### Курс АСИТ

Пользователь задаёт курс, назначенный врачом (хранение: `app_settings` → `asitCourse:{profileId}`):

| Поле | Описание |
|------|----------|
| Аллерген | Целевой аллерген курса |
| Препарат | Торговое название |
| Путь | SLIT (подъязычная) / SCIT (подкожная) |
| Фаза | Наращивание / поддерживающая |
| Схема | Текстовое описание по назначению врача |

### Запись приёма в дневнике

Расширенный раздел «АСИТ»: аллерген, препарат, путь, фаза, дата/время, номер дозы, соблюдение графика, местная и системная реакция. При активном курсе поля **автозаполняются** из настроек.

### Сводка и отчёт

- Карточка **АСИТ** на экране дневника: приёмы за 30 дней, в срок / пропущено
- PDF-отчёт: блок **«Сводка АСИТ»** с курсом и комплаенсом

### Границы

Приложение **не назначает и не корректирует** дозы АСИТ (`ASIT_DISCLAIMER`).

## 6. Пищевая и лекарственная аллергия

### Реестр пищевых исключений

Пользователь дополняет аллергены профиля списком исключений (хранение: `app_settings` → `foodDrugRegistry:{profileId}`):

| Поле | Описание |
|------|----------|
| Дополнительные исключения | Продукты сверх аллергенов профиля |
| Заметки для врача | Строгость диеты, переносимость следов |

Непереносимые ЛС хранятся в **паспорте SOS** (`drugIntolerances`) и используются для предупреждений.

### Записи в дневнике

**Питание** — источник (сканер / вручную), автоподстановка из последнего сканирования за 24 ч, тип клинической реакции (ораллергический синдром, ЖКТ, кожа, дыхание, анафилаксия).

**Лекарство** — при вводе названия препарата проверяется совпадение с непереносимыми ЛС из SOS; при совпадении показывается предупреждение. Отдельно фиксируется тяжесть побочной реакции.

### Карточки на экране дневника

- **Пищевая аллергия** — при типе `food` или пищевых аллергенах в профиле: список исключений, KPI за 30 дней
- **Лекарственная аллергия** — при типе `drug` или непереносимых ЛС в SOS: список препаратов, предупреждения за 30 дней

### Отчёт для врача

PDF-отчёт: блок **«Пищевая и лекарственная аллергия»** — сводка исключений, непереносимых ЛС, записей о питании и лекарствах за период.

### Границы

Приложение **не назначает диету и не отменяет препараты** (`FOOD_DRUG_DISCLAIMER`).

## 7. Границы и дисклеймеры

- Все шкалы — **самоотчёт** пользователя/родителя.
- Алгоритм анафилаксии — **общеинформационный**, план действий задаёт врач.
- Отчёт PDF не является медицинской документацией (см. `DOCTOR_REPORT_DISCLAIMER`).
