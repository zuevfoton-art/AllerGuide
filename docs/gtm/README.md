Маркетинговые материалы для go-to-market стратегии. Стиль: **Clinical Calm** ([`docs/brand/brand-preview.html`](../brand/brand-preview.html)).

## Экспорт в PDF

1. Откройте HTML-файл в браузере (Chrome / Edge).
2. `Ctrl+P` / `⌘P` → «Сохранить как PDF».
3. Формат: **A4**, поля по умолчанию, фоновая графика включена.

Для one-pager достаточно одной страницы. Doctor brief — 2–3 страницы.

## Перед печатью

- Замените placeholder QR-кода на реальные ссылки App Store / Google Play.
- Обновите контактные данные в пресс-ките (email, телефон пресс-службы).
- Убедитесь, что co-marketing соглашение с ADAIR подписано (использование бренда АДАИР).
