Кратко: AllerGuide — мобильное приложение (iOS, Android; Web с ограничениями), которое помогает пациентам структурированно вести наблюдения, проверять продукты по профилю аллергий, пользоваться картой клиник АДАИР и формировать PDF-отчёт для визита. Приложение не ставит диагноз и не заменяет назначения врача. Научный руководитель — д.м.н., проф. Ю.С. Смолкин (Президент АДАИР). Offline-first: ядро работает без сети.

Зачем рекомендовать пациенту

  • Структурированный дневник — 10 типов записей + клинические шкалы (ACT, ARIA-lite, SCORAD-lite, UAS7)
  • PDF-отчёт за 7 / 14 / 30 дней с блоками, timeline, кодами ICD-11 / SNOMED и сводкой SOS-паспорта
  • Аллергопаспорт SOS — адреналин, степени анафилаксии, план действий, share / экспорт PDF
  • Сканер — 4 режима (продукт, меню, лекарство, косметика); риск: direct / cross / traces / unknown
  • Карта АДАИР — клиники и врачи ассоциации + слой пыления и мест
  • Offline-first — профили, дневник, SOS и базовый сканер без постоянного интернета

Как пациент использует приложение

1
Онбординг — сценарий (себя / ребёнка / оба), аллергены из каталога, экстренные контакты
2
Ежедневно — дневник, сканер продуктов, индекс дня, при необходимости карта пыления
3
Перед визитом — PDF-отчёт за 14–30 дней с нужными блоками и timeline
4
На приёме / в экстренной ситуации — PDF или SOS-паспорт (экран / share / PDF)

Рекомендации для врача

Кому особенно подходит

  • Родители детей с пищевой аллергией (профиль ребёнка + полный SOS-паспорт)
  • Пациенты с поллинозом / астмой (индекс + пикфлоуметрия + ACT-prompt)
  • Пациенты на АСИТ (трекинг схемы и субъективной реакции)
  • Инсектная аллергия (записи об укусах + план действий)
  • Пациенты, которым сложно систематически вести бумажный дневник

Как рекомендовать на приёме

  1. Покажите QR-код или дайте one-pager для пациента
  2. Попросите создать профиль с актуальным списком аллергенов (при возможности — отметить confirmedBy)
  3. Уточните: «Принесите PDF-отчёт за 14–30 дней на следующий визит»
  4. Для детей — заполнить SOS: адреналин, план действий, контакты

Ограничения (важно озвучить пациенту)

  • Результат сканера — предварительный; учитывает traces / «may contain», но не исключает индивидуальной реакции
  • OCR меню и этикеток — вспомогательный режим; надёжнее ручной ввод / штрихкод продукта
  • PDF-отчёт — не медицинская документация; данные вносит пациент
  • Wellness index — ориентир, не заменяет клиническую оценку
  • Маркет — информационная подборка, не полноценный магазин и не назначение врача
  • Экспертный контент АДАИР — справочный
