Кратко: AllerGuide — мобильное приложение (iOS, Android), которое помогает пациентам структурированно вести наблюдения, проверять продукты по профилю аллергий и формировать PDF-отчёт для визита. Приложение не ставит диагноз и не заменяет назначения врача. Разработано при участии АДАИР; научный руководитель — д.м.н., проф. Ю.С. Смолкин.

Зачем рекомендовать пациенту

  • Структурированный дневник вместо разрозненных записей — симптомы, питание, лекарства, пикфлоуметрия, АСИТ, триггеры
  • PDF-отчёт за 7 / 14 / 30 дней с выбором блоков — экономит время приёма
  • Кодирование аллергенов (ICD-11 / SNOMED crosswalk) в отчёте для врача
  • Клинические шкалы из дневника: ACT (астма), ARIA (ринит), SCORAD, UAS7 — интегрированы в индекс самочувствия
  • SOS-экран — аллергопаспорт для экстренных ситуаций (особенно у детей)
  • Offline-first — данные на устройстве; не требует постоянного интернета

Как пациент использует приложение

1
Онбординг — выбор сценария (себя / ребёнка / оба), заполнение аллергенов из каталога АДАИР
2
Ежедневно — быстрые записи в дневник; сканирование новых продуктов; просмотр индекса дня
3
Перед визитом — формирование PDF-отчёта за нужный период с выбранными блоками
4
На приёме — показывает PDF или историю в приложении; при необходимости — SOS-экран

Рекомендации для врача

Кому особенно подходит

  • Родители детей с пищевой аллергией (профиль ребёнка + SOS)
  • Пациенты с поллинозом / астмой (индекс + пикфлоуметрия + ACT-prompt раз в 4 недели)
  • Пациенты на АСИТ (трекинг инъекций и субъективной реакции)
  • Пациенты, которым сложно систематически вести бумажный дневник

Как рекомендовать на приёме

  1. Покажите QR-код или дайте one-pager (docs/gtm/patient-one-pager.html)
  2. Попросите создать профиль с актуальным списком аллергенов
  3. Уточните: «Принесите PDF-отчёт за 14–30 дней на следующий визит»
  4. Для детей — обязательно заполнить SOS и экстренные контакты

Ограничения (важно озвучить пациенту)

  • Результат сканера — предварительный; не исключает индивидуальной реакции и следов («may contain»)
  • PDF-отчёт — не медицинская документация; данные вносит пациент
  • Wellness index — ориентир, не заменяет клиническую оценку
  • Экспертный контент АДАИР — справочный, не является назначением
